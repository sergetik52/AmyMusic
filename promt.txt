## Текущий проект

Сейчас в проекте есть:

- экран «Моя волна»;
- экран поиска;
- экран чартов;
- экран коллекции;
- история прослушивания;
- любимые треки;
- mini-player;
- fullscreen player;
- нижняя навигация из 4 вкладок;
- PWA manifest с `display: standalone`;
- `viewport-fit=cover`;
- тёмная тема;
- основной accent `#8341EF`.

Текущая мобильная навигация находится в `src/mobile/MobileLayout.jsx`.

Сейчас navigation bar реализован как полноширинная тёмная панель внизу экрана. Нужно заменить её на плавающий Liquid Glass dock в стиле современных iOS 26-приложений.

При текущей проверке были обнаружены проблемы:

- search filters создают горизонтальный overflow;
- часть элементов слишком мелкая для комфортного touch-взаимодействия;
- подписи tab bar слишком маленькие;
- mini-player и navigation визуально сливаются;
- safe-area учтена частично;
- необходимо проверить клавиатуру, Dynamic Island, Android gesture navigation, landscape и узкие экраны 320–360 px.

## Визуальное направление

Создай стиль:

- premium dark music app;
- restrained Liquid Glass;
- чёрный фон;
- яркие обложки и waveform как основной визуальный контент;
- glass только на плавающих функциональных слоях;
- минимум декоративного шума;
- никаких стандартных AI-интерфейсов с большим количеством фиолетовых градиентов;
- никаких emoji вместо иконок;
- никаких glass-карточек для каждого элемента списка.

Сохрани визуальную основу AmyMusic:

primary text: #ffffff

Используй #8341EF только для:

Liquid Glass navigation dock
Нижняя навигация должна выглядеть как floating Liquid Glass dock, а не как чёрная полоса от края до края.
Структура:
[ Liquid Glass mini-player ]

      [ Поиск | Моя волна | Чарты | Коллекция ]
Требования:
- dock плавает над контентом;
- отступает от левого, правого и нижнего края;
- имеет скругление 24–28 px;
- контент страницы визуально продолжается под ним;
- последний элемент списка не скрывается под dock;
- navigation и mini-player должны быть отдельными glass-поверхностями;
- не объединять их в одну огромную панель.
Базовый CSS-направление:
.mobile-nav-dock {
  position: fixed;
  left: max(12px, env(safe-area-inset-left));
  right: max(12px, env(safe-area-inset-right));
  bottom: calc(10px + env(safe-area-inset-bottom));

  min-height: 64px;
  padding: 6px;

  border: 1px solid rgba(255, 255, 255, 0.14);
  border-radius: 26px;

  background: rgba(20, 20, 24, 0.64);

  backdrop-filter: blur(28px) saturate(1.45);
  -webkit-backdrop-filter: blur(28px) saturate(1.45);

  box-shadow:
    0 12px 40px rgba(0, 0, 0, 0.42),
    inset 0 1px 0 rgba(255, 255, 255, 0.12);

  z-index: 50;
}
Liquid Glass разрешён только для:
- navigation dock;
- mini-player;
- fullscreen player;
- sheets;
- dialogs;
- floating menus.
Не использовать Liquid Glass на:
- фоне страницы;
- карточках треков;
- списках;
- album covers;
- hero content;
- каждом отдельном control.
Navigation tabs
Сохрани 4 вкладки:
- Поиск;
- Моя волна;
- Чарты;
- Коллекция.
Для каждого tab:
- минимальная touch-зона 44×44 px;
- icon 21–23 px;
- label 11–12 px;
- aria-current="page" или aria-selected;
- visible focus-visible состояние;
- active state должен быть заметен не только цветом;
- inactive state не должен выглядеть невидимым;
- не использовать только opacity: 0.4;
- не использовать больше 4–5 главных tabs;
- tab bar используется только для навигации, не для действий.
Активное состояние:
.mobile-nav-item[data-active="true"] {
  color: #ffffff;

  background: color-mix(
    in srgb,
    var(--theme-accent) 24%,
    transparent
  );

  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.1),
    0 4px 16px color-mix(
      in srgb,
      var(--theme-accent) 24%,
      transparent
    );
}
Liquid Glass mini-player
Mini-player должен быть отдельной стеклянной карточкой над navigation dock:
[ cover ] [ title / artist ] [ like ] [ play ]
Требования:
- располагается на 8–12 px выше navigation dock;
- скругление 18–22 px;
- cover 48–56 px;
- play button минимум 44×44 px;
- tap по track area открывает fullscreen player;
- title и artist максимум в 2 строки;
- на ширине 320–360 px оставить только cover, title/artist и play;
- secondary controls перенести в Sheet/Drawer;
- mini-player не должен сливаться визуально с tab bar;
- пустое состояние показывает «Нет трека» и «Трек не загружен».
Safe Area и viewport
Добавь единые safe-area tokens:
:root {
  --safe-top: env(safe-area-inset-top, 0px);
  --safe-right: env(safe-area-inset-right, 0px);
  --safe-bottom: env(safe-area-inset-bottom, 0px);
  --safe-left: env(safe-area-inset-left, 0px);
}
Используй:
.app-shell {
  min-height: 100svh;
  height: 100dvh;
  padding-top: var(--safe-top);
  padding-left: max(16px, var(--safe-left));
  padding-right: max(16px, var(--safe-right));
}

.mobile-nav-dock {
  left: max(12px, var(--safe-left));
  right: max(12px, var(--safe-right));
  bottom: calc(10px + var(--safe-bottom));
}
Требования:
- не использовать только 100vh;
- использовать 100dvh для текущей видимой высоты;
- использовать 100svh как минимальную fallback-высоту;
- учитывать safe area сверху, снизу, слева и справа;
- не дублировать safe-area-inset-top;
- не перекрывать home indicator;
- корректно работать с Dynamic Island;
- корректно работать с Android gesture navigation;
- корректно работать в landscape;
- корректно работать на foldable-устройствах;
- фон glass dock должен доходить до safe area, а интерактивные элементы должны находиться внутри неё.
Контент должен иметь нижний padding:
padding-bottom: calc(
  var(--mini-player-height) +
  var(--nav-dock-height) +
  32px +
  env(safe-area-inset-bottom)
);
Responsive layout
Обязательно проверить:
- 320×568;
- 360×800;
- 375×812;
- 390×844;
- 430×932;
- tablet width;
- landscape;
- iPhone с notch;
- iPhone с Dynamic Island;
- Android Chrome;
- Android gesture navigation;
- standalone PWA режим;
- browser mode с адресной строкой;

Не допускай:

- fixed heights, которые ломаются при увеличенном тексте.
Scroll behavior
При прокрутке:
- контент визуально проходит под glass dock;
- navigation dock остаётся доступным;
- mini-player может компактно сворачиваться при scroll down;
- при scroll up mini-player возвращается;
- dock не должен исчезать полностью;
- анимации должны быть короткими и отменяемыми;
- при prefers-reduced-motion: reduce отключить transform-анимации;
- добавить мягкий scroll-edge fade возле glass navigation.

Accessibility
Обеспечь:
- контраст обычного текста минимум 4.5:1;
- контраст крупного/bold текста минимум 3:1;
- все icon-only buttons имеют aria-label;
- состояние не передаётся только цветом;
- работает keyboard focus;
- VoiceOver/NVDA читают navigation и player;
- есть альтернативы жестам;
- свайп не является единственным способом закрытия;
- кнопки имеют минимум 44×44 px;
- content доступен при увеличенном системном тексте;
- loading, empty, error и offline states доступны скринридеру.
Liquid Glass accessibility fallback
Для пользователей с отключённой прозрачностью или повышенной контрастностью:

  .mobile-mini-player {
    background: #17171b;
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
    border-color: rgba(255, 255, 255, 0.28);
  }
}
Если браузер не поддерживает backdrop-filter, использовать непрозрачный fallback.
Motion
Используй:
- tap feedback: 120–180 ms;
- sheet transition: 220–300 ms;
- короткие cancellable-анимации;
- никакой постоянной декоративной пульсации без необходимости;
- никакого motion как единственного способа передать состояние.
При prefers-reduced-motion: reduce отключить:
- parallax;
- fluid blob animations;
- масштабные переходы;
- постоянные вращения;
- morphing glass effects.
